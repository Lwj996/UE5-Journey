# Scratchpad · 随手记

> 工作之余、通勤路上、午休时冒出来的零碎观察。和 UE5 学习无直接关系，但值得留下痕迹的东西都进这里。
>
> **2026-05-14 起新增子目录** [`life/`](./life/) —— 专收**关于"我作为一个人在某一刻的判断"的人生日记**。普通 scratchpad 是「对外的观察」，life/ 是「对内的记录」。

## 这里收什么（普通 scratchpad）

- 🧪 **AI 工具体验**：用了某个新模型/工具的真实感受
- 👀 **行业观察**：游戏/AI/科技圈值得记一笔的事
- 💭 **想法闪念**：突然冒出的产品 idea、技术疑问、轻量人生感慨
- 📚 **碎片阅读**：刷到的好文章、好视频，简短点评
- 🤔 **困惑与争议**：尚未理清但想留个钩子的问题
- 🛠️ **学习方法反思**：拖延自剖、节奏调整等"修工具"类的内容

## 这里不收什么

- ❌ 当天的 UE 学习记录 → 去 [`journal/`](../journal/)
- ❌ 整理好的知识笔记 → 去 [`notes/`](../notes/)
- ❌ 长期计划 → 去 [`docs/`](../docs/)
- ❌ 重大人生抉择 / 核心恐惧 / 转折点 → 去 [`life/`](./life/)

## 命名规范

`YYYY-MM-DD-topic-slug.md`

例：
- `2026-04-23-gpt-img2-observations.md`
- `2026-05-10-ai-coding-rant.md`

## 写作规范

**比 journal 宽松**：
- 不强制双语（中文为主，关键术语保留英文即可）
- 不强制结构化模板
- 不强制凑字数——一句话也是一篇
- 但**日期和主题必须在标题或开头说明**
