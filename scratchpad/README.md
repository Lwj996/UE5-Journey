## 这里收什么（普通 scratchpad）

- 🤖 **AI 工具体验**：用了某个新模型 / 工具的真实感受
- 👀 **行业观察**：游戏 / AI / 科技圈值得记一笔的事
- 🛠️ **学习方法反思（修工具类）**：拖延自剖、节奏调整、5 分钟启动法等
- 💭 **想法闪念**：突然冒出的产品 idea、技术疑问、轻量人生感慨
- 📚 **碎片阅读**：刷到的好文章 / 视频，简短点评

## 不收什么

- ❌ 当天的 UE 学习记录 → [`journal/`](../journal/)
- ❌ 整理好的知识笔记 → [`notes/`](../notes/)
- ❌ 长期计划 → [`docs/`](../docs/)
- ❌ **重大人生抉择 / 核心恐惧 / 转折点** → [`life/`](./life/)
