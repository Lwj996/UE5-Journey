## 学英语原则

1. **不背托福雅思词汇** — 只背 UE 相关
2. **看英文教程时不开中文字幕** — 开英文字幕即可
3. **用 Anki 复习**（[下载](https://apps.ankiweb.net/)）
4. **写日志时尝试加几句英文**
5. **GitHub commit message 全英文**（从第 1 天就养成习惯）
