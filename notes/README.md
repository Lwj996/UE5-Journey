# Notes

主题式笔记，和日志不同——**笔记按主题组织，随时可查**。

## 目录

### UE5 Concepts (`ue5-concepts/`)
UE 核心概念的结构化笔记：Actor 框架、Blueprint、GAS、渲染、动画等。

### C++ (`cpp/`)
UE 方言 C++ 的笔记：UCLASS/UPROPERTY、容器、指针、Delegate、模板等。

### English (`english/`)
英语学习资源：技术词汇、简历表达、面试常用句。

---

## 记笔记原则

1. **先写问题，再写答案** — "为什么 Pawn 要有 Controller？" 比 "Pawn 有 Controller" 有用 10 倍
2. **贴代码片段** — 好代码永远值得抄
3. **画图** — 架构图 / 类关系图比 100 行文字强
4. **链接原始资料** — 方便以后回溯
5. **用自己的话重写** — 抄别人的笔记等于没记

## 文件命名

- `NN-topic-name.md`（带数字前缀，便于排序）
- 例：`01-editor-basics.md`、`02-actor-framework.md`
