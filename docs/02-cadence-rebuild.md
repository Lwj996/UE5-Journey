```

周六        UE = 3h
周日        UE = 3h
─────────────────────────────────────
```

## 周末模块（标准模板）

### 周六 · 3h · 主进度日

| 时段 | 内容 |
|------|------|
| 0:00 - 0:10 | 开 `journal/YYYY-MM-DD-day-XX.md`，写一句"今天打算做什么" |
| 0:10 - 2:30 | 跟教程 / 实操（核心 2h 20min） |
| 2:30 - 2:45 | 把今天 1-2 个新概念写进 `notes/ue5-concepts/` |
| 2:45 - 3:00 | 日志双语补全 + commit + push |

### 周日 · 3h · 巩固 + 周报

| 时段 | 内容 |
|------|------|
| 0:00 - 1:30 | 把周六的内容**自己复现一遍**（不看教程） |
| 1:30 - 2:30 | 继续推进 / 探索新章节 |
| 2:30 - 3:00 | 写 `journal/YYYY-MM-DD-week-XX-summary.md` + commit + push |

> **每月最后一个周日**：合并 `dev` → `main`（不再每周合，减少仪式负担）。

## 假期 / 出游 / 加班的下限规则

| 场景 | UE 下限 |
|------|--------|
| 普通周末 | 周末两天合计 6h |
| 加班 / 朋友局 / 出游 1 天 | 当周 ≥ 3h（保住一天） |
| 整周出游 / 长假 | **允许 0h**，但**假期结束第一晚必须回到桌前**（哪怕只 15min） |

> 04-27 自剖里的 **Two-Day Rule** 升级：
> 周末连塌 = 红色警报；
> 假期连塌 = 假期后第一晚必须回桌（哪怕 15min）。

## Roadmap 时长换算（旧 → 新）

| 阶段 | 旧投入 | 新投入 | 月数（弹性） |
|---|---|---|---|
| 1 个月（旧）= 88h | 88h | ~26h | 旧 1 月 ≈ 新 3 月 |
| 12 个月总学时 | 1056h（理论） | ~300h（保守） | 同样 12 个月 |

**含义**：12 个月的总目标（投海外 Gameplay Programmer）**保留**，但内容会**主动收敛**：
- 砍掉 2-3 个非核心月（如纯工具链、独立的 Python 编辑器模块）
- Roguelike 项目从"完整发布"调成"**核心循环可玩 + itch.io demo**"
- C++ 不追"完整入门"，只追"能在 GAS 里写技能 + 能改蓝图基类"

> **删减不丢人——按假目标跑 3 个月然后崩盘才丢人。**

## 不再做的事（删除项）

- ❌ 工作日"21:00 准时坐到桌前"——和"必须 2h"绑死了，绑住就执行不了。改成**周末为主**。
- ❌ "每天至少 1 次 commit"——工作日不学就没东西可 commit。改成**有内容就 commit**，没内容不强求。
- ❌ "每周日合并 dev → main"——降低到**每月最后一个周日**。
- ❌ 任何"如果某天没做，第二天补 2 倍"的规则——补偿心态是塌方的最大温床。

## 评估周期

每 4 周（即每个月最后一个周日）做一次回顾：

- [ ] 这 4 周里有几周完成了 6h？
- [ ] 平均周完成度（实际/计划）= ?%
- [ ] 计划是否还需要再调？
- [ ] roadmap 阶段进度是否需要顺延？

> **80% 完成率 = 健康**。
> **持续 < 50% = 计划再砍。**
> **持续 > 100% = 可以考虑加到 8h/周，但不必急。**
