## 技术栈聚焦（只学 / 不学清单）

### ✅ 必学（按优先级）

1. **蓝图基础**（变量 / 函数 / 事件 / 接口 BPI）
2. **Enhanced Input**（UE 5.x 输入系统，新手第一道坎）
3. **Character / Pawn / Controller 框架**（小品游戏不需要 GAS）
4. **Multiplayer Replication**（co-op 核心：Replicated / RepNotify / RPC）
5. **物理交互**（OverlapEvent / Trace / Physics Constraint）
6. **UMG**（HUD / 主菜单 / 设置 / 大厅）
7. **关卡设计**（World Composition / Level Streaming 基础）
8. **音效系统**（Sound Cue / Spatial Audio = 恐怖核心）
9. **Steam SDK 接入**（Online Subsystem Steam）
10. **打包发布**（Shipping Build / Steam Pipe 上传）

### ⚠️ 学一点就够

- C++（只在性能瓶颈 / Steam SDK 集成时上）
- Niagara 粒子（少量 jump scare 视效够用）
- Animation Blueprint（用 Mixamo 动画 retarget 即可）

### ❌ 不学（小品 co-op 用不到）

- Nanite / Lumen 深度优化（low-poly 不需要）
- Gameplay Ability System（GAS）
- World Partition 大世界
- 复杂渲染管线
- 主机平台移植
- 反作弊系统（小品休闲游戏无所谓）

> **从今天起从"6h/周 cadence-rebuild"切换到"项目驱动节奏"。**
> `docs/02-cadence-rebuild.md` 作废。

| 阶段 | UE 周时长 | 工作日 | 周末 |
|---|---|---|---|

1. **周末 ≥ 4h 是底线**（没有这个，整个 18 月计划不成立）

3. **永远从 Template 改起**，不从零搭——Third Person Template + Multiplayer Subsystem Plugin 是起点
4. **遇到难点先用 AI 翻译错误**，再问社区，**实在不行才看视频教程**——AI 是第一查询入口

## 第一个 Mini-prototype（阶段 1）· 设计草案

> 这是 **9-10 月的目标**，不是现在做。但先写下来给未来的我看。

**核心循环**（致命公司式简化版）：

```
进入关卡 → 黑暗中找物品 → 听到怪物声音 → 躲 / 跑 → 把物品带回基地 → 加分 → 下一关
```

**MVP 必须有**：
- 3 人联机（Listen Server 即可）
- 第一人称视角
- 手电筒（电池系统）
- 1 种物品（可拾起 / 可丢下 / 可放进背包）
- 1 个怪物（追玩家，靠声音判断）
- 1 个回收点（把物品放进去 = 得分）
- 1 张关卡（简单废墟 / 仓库）

**MVP 没有**：
- 不做多关卡
- 不做剧情
- 不做养成
- 不做商店
- 不做 UI 美化（能跑就行）

**用 AI 干掉的活**：
- 美术：Midjourney 出 concept → Meshy 图转 3D / 直接 Fab 找类似
- 音效：ElevenLabs（脚步 / 怪物吼 / 物品拾取）
- 音乐：Suno 出氛围音乐（loop）
- 商店页文案：未来用
