# 学习资源清单

> 分级整理，打 ⭐ 的是必看。

---

## 官方（最权威）

- ⭐ [Epic Developer Community](https://dev.epicgames.com/community/) — 官方学习平台
- ⭐ [UE 5.7 Starter Course](https://dev.epicgames.com/community/learning/tutorials/bE7Z/unreal-engine-5-7-starter-course) — 零基础入门课（英文）
- [Official Documentation](https://dev.epicgames.com/documentation/en-us/unreal-engine/) — 文档（英文）
- [Unreal Engine Learning Hub](https://www.unrealengine.com/en-US/onlinelearning-courses) — 免费官方课
- [Inside Unreal (YouTube)](https://www.youtube.com/@UnrealEngine/playlists) — Epic 工程师直播

## C++ 专项（第 3 个月起）

- ⭐ Stephen Ulibarri《Unreal Engine 5 C++ Developer》— Udemy，40h，英文，业界公认入门最佳
- [UE C++ Programming Tutorials](https://dev.epicgames.com/documentation/en-us/unreal-engine/unreal-engine-c-plus-plus-programming-tutorials)
- Tom Looman 的博客：[tomlooman.com](https://www.tomlooman.com/) — 前 Epic 工程师，最好的 UE C++ 博客

## GAS（第 5 个月起）

- ⭐ [tranek/GASDocumentation](https://github.com/tranek/GASDocumentation) — GitHub 7k+ stars，GAS 圣经
- Stephen Ulibarri《Unreal Engine 5 GAS Top-Down RPG》— Udemy，GAS 专项课

## 多人联机（第 7 个月起）

- Stephen Ulibarri《Multiplayer Steam Subsystem》— Udemy
- [UE Networking Docs](https://dev.epicgames.com/documentation/en-us/unreal-engine/networking-and-multiplayer-in-unreal-engine)

## 性能优化（第 8 个月起）

- [Unreal Insights Documentation](https://dev.epicgames.com/documentation/en-us/unreal-engine/unreal-insights-in-unreal-engine)
- [RenderDoc](https://renderdoc.org/) — 帧分析工具
- GDC Talks on YouTube: 搜 "Unreal Engine Optimization GDC"

## YouTube 频道（免费且质量高）

### 英文
- ⭐ [Gorka Games](https://www.youtube.com/@GorkaGames) — 新手友好，有很多俯视角 Roguelike 教程
- ⭐ [Matt Aspland](https://www.youtube.com/@MattAspland) — 蓝图 101 系列最全
- [Ryan Laley](https://www.youtube.com/@RyanLaley) — 系统性教程
- [CodeLikeMe](https://www.youtube.com/@CodeLikeMe) — UE C++
- [Reids Channel](https://www.youtube.com/@ReidsChannel) — 进阶技巧
- [Ben Ormstad](https://www.youtube.com/@BenOrmstad) — GAS 教程

### 中文（少量使用）
- B 站搜 "UE5 入门"、"虚幻引擎" 找评论区活跃的 UP 主
- 初期帮助理解概念，但**中文资源永远比英文慢 6 个月**，后期必须转英文

## 英语学习工具

## 工具软件

### 必装
- **Visual Studio 2022 Community** — UE C++ 开发
- **Git + Git LFS** — 版本控制
- **Rider for Unreal Engine**（可选付费）— 比 VS 好用的 IDE

### 推荐
- **ScreenToGif** — 录 GIF，发仓库用
- **Obsidian** — Markdown 笔记（比 VS Code 好做长期笔记）
- **Excalidraw**（网页版）— 画架构图、UML
- **Blender** — 免费 3D 建模
- **DaVinci Resolve** — 免费剪辑，Devlog 视频用
