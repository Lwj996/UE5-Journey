# Journal

每日/每周学习日志，按时间顺序倒序排列。

## 命名规范

- 每日：`YYYY-MM-DD-day-XX.md`
- 周报：`YYYY-MM-DD-week-XX-summary.md`
- 月报：`YYYY-MM-month-XX-summary.md`

## 写作要求

- 模板见 [`TEMPLATE.md`](./TEMPLATE.md)
- 不求长，求真实（1 分钟也比不写强）
- 问题 / 坑 / 反思 比"我学了什么"更有价值
- 每周日写一篇周报，做减法而不是加法（复盘本周 3 件最重要的事）
