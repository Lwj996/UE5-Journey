## ③ 学到的 3 个新东西

**🇨🇳**
1. **View Mode**：编辑器视口不是只有"正常显示"，可以切到 Wireframe / Lighting Only / Unlit 等，**不同模式排查不同问题**（光照异常切 Lighting Only，模型穿模切 Wireframe）。
2. **Surface Snap（贴附法线）**：放置物件时让它自动贴着另一个表面，按地形角度旋转——比手动调省太多时间。
3. **复制 vs 拷贝**：Duplicate（Alt + 拖动）会**就地复制并保留所有属性**，Copy/Paste 会丢失一些上下文（比如绑定关系）——**默认用 Duplicate**。

**🇬🇧** *(AI-translated)*
1. **View Mode**: viewport isn't just "normal" — switch to Wireframe / Lighting Only / Unlit to **diagnose different problems** (lighting bugs → Lighting Only; clipping → Wireframe).
2. **Surface Snap (snap to normal)**: drop an object and it auto-aligns to the surface beneath, rotating with terrain — way faster than manual.
3. **Copy vs Duplicate**: Duplicate (Alt + drag) **preserves all properties in place**; Copy/Paste loses some context (like bindings) — **default to Duplicate**.
